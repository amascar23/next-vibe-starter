# Antigravity Vibe Coding Rules

This repository enforces an anti-slop, PRD-first methodology:

1. **Wajib Interview Terlebih Dahulu**:
   Saat pengguna memulai proyek baru atau ide baru, jangan langsung membuat file kode. Ajukan 5-8 pertanyaan terstruktur mengenai target pengguna, MVP scope, flow halaman, database, dan gaya visual. Tulis hasilnya ke `PRD.md`.
2. **Breakdown Task**:
   Setelah `PRD.md` disetujui, pecah ke dalam `AGENTS.md` dalam bentuk task-task atomik.
3. **Eksekusi Bertahap**:
   Kerjakan satu task dalam satu waktu menggunakan Next.js 15 App Router, TypeScript ketat, dan Tailwind CSS.
